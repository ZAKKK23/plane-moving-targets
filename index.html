plane-moving-targets

A Voronoi Tessellation Population (VTP) agent simulation with moving targets — five target-motion variants of the same underlying model, each with a MATLAB implementation and a dependency-light browser port.

Delaunay / Voronoi MATLAB + JS ports no build step 5 target-motion variants

Every variant below shares the same VTP agent core: repulsion from the nearest Delaunay neighbor, alignment with neighbors' headings, and homing toward the nearest target — blended by the same two live-editable constants, ν (alignment strength) and L (interaction length scale). What differs between them is purely how the targets move.

Tusi couple

Targets oscillate in a straight line, generated by a small circle rolling inside a fixed circle — the classical mechanism for turning two rotations into linear motion. Includes live "cells near each target" radius/time-series charts and CSV/PNG export.

Rectilinear + bounce

The simplest target motion: a fixed heading and speed, bouncing elastically off the walls of a box — classic billiard-ball motion.

Stadium track

Targets ride a closed "stadium" loop — two straight sides joined by two half-circles, like a running track — spaced evenly and moving together around it.

Aligned: one oscillating

A chosen number of straight-line targets on parallel horizontal lanes, plus one additional target that oscillates in y. All targets share a single x-coordinate at every instant.

Aligned: multiple oscillating

The inverse: a chosen number of independently-parametrized oscillating targets (each own height/amplitude/ω), plus one straight-line target. Same shared-x alignment as above.

Structure

  • assets/ — shared site styling and the vendored D3-Delaunay library, used by every variant
  • variants/<name>/ — one self-contained variant: its own index.html, its own assets/sim.js + assets/app.js (the simulation engine and page wiring, which differ per variant), and its own matlab/ folder with the original MATLAB implementation

Each variant page has its own "about / live simulation / matlab version" tabs, plus a link back to this page at the top.
