plane-moving-targets (aligned)

A Voronoi Tessellation Population (VTP) agent simulation with moving targets, ported from MATLAB to a dependency-light browser build.

Delaunay / Voronoi aligned straight-line + sinusoidal target motion MATLAB + JS ports no build step

You choose a number of straight-line targets (0-5). Each one travels along its own fixed-height horizontal line — like several parallel lanes. One more target is always added on top of those: it moves sinusoidally in y (its own height, amplitude, and ω sliders) while still moving horizontally like all the others, so it travels in a wavy, oscillating path.

Every target — including the oscillating one — shares a single horizontal speed and a single shared x-coordinate. There's only one x(t) in the whole system, so all targets are aligned (exactly the same x) at every instant, not just when they start.

Agents ("cells") respond to three local forces computed from their Delaunay neighborhood: a short-range repulsion from the nearest neighbor, an alignment pull toward neighbors heading the same way, and a homing pull toward whichever target is currently closest. Each step is capped by an estimate of the agent's own Voronoi cell size, so a crowded agent can't leap over its neighbors. Two constants shape that balance: ν (alignment strength) and L (interaction length scale) — both live-editable on the live simulation tab, same as the shared horizontal speed.

Two implementations, one model

  • index.html (this page, live simulation tab) — a JavaScript/Canvas + D3-Delaunay port that runs directly in the browser, no install.
  • matlab/dynamics.m — the original MATLAB implementation, browsable under the matlab version tab.

MATLAB version

The original implementation, in matlab/.

Requires base MATLAB only (delaunayTriangulation, polyshape — no extra toolboxes). Run:

cd matlab
matlab -r dynamics

...or open dynamics.m in the MATLAB editor and run it. You'll be prompted for the number of straight-line targets (0–5); one oscillating target is always added on top. An interactive figure then opens with a control panel (agent speed, ν, L, shared horizontal speed, each straight target's height, and the oscillating target's height/amplitude/ω — Apply / Pause / Reset Targets).
