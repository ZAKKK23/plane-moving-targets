plane-moving-targets (rectilinear)

A Voronoi Tessellation Population (VTP) agent simulation with moving targets, ported from MATLAB to a dependency-light browser build.

Delaunay / Voronoi rectilinear + bounce target motion MATLAB + JS ports no build step

Each target here moves the simplest way possible: a straight line at a fixed heading and speed, bouncing elastically off the walls of a square box — the classic billiard-ball motion.

Agents ("cells") respond to three local forces computed from their Delaunay neighborhood: a short-range repulsion from the nearest neighbor, an alignment pull toward neighbors heading the same way, and a homing pull toward whichever target is currently closest. Each step is capped by an estimate of the agent's own Voronoi cell size, so a crowded agent can't leap over its neighbors. Two constants shape that balance: ν (alignment strength) and L (interaction length scale) — both live-editable on the live simulation tab.

Two implementations, one model

  • index.html (this page, live simulation tab) — a JavaScript/Canvas + D3-Delaunay port that runs directly in the browser, no install.
  • matlab/dynamics.m — the original MATLAB implementation, browsable under the matlab version tab.

MATLAB version

The original implementation, in matlab/.

Requires base MATLAB only (delaunayTriangulation, polyshape — no extra toolboxes). Run:

cd matlab
matlab -r dynamics

...or open dynamics.m in the MATLAB editor and run it. You'll be prompted for the number of targets (1–6), then an interactive figure opens with a live plot of the swarm plus a control panel (target speed, heading, agent speed, ν, L, Apply / Pause / Reset Targets).
