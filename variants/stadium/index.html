plane-moving-targets (stadium)

A Voronoi Tessellation Population (VTP) agent simulation with moving targets, ported from MATLAB to a dependency-light browser build.

Delaunay / Voronoi closed stadium-track target motion MATLAB + JS ports no build step

Targets here ride a closed stadium track — two straight sides joined by two half-circles, like a running track — instead of a straight line or a bounded corridor. You choose how many targets ride the loop; they're spaced evenly along it and all move together in one direction.

Every target shares a single arc-length position, offset by a constant spacing, so their along-track spacing is exact and never drifts — even while you change spacing, speed, or the track's own shape live.

Agents ("cells") respond to three local forces computed from their Delaunay neighborhood: a short-range repulsion from the nearest neighbor, an alignment pull toward neighbors heading the same way, and a homing pull toward whichever target is currently closest. Each step is capped by an estimate of the agent's own Voronoi cell size, so a crowded agent can't leap over its neighbors. Two constants shape that balance: ν (alignment strength) and L (interaction length scale) — both live-editable on the live simulation tab, alongside the track's own shape and the targets' spacing/speed.

Two implementations, one model

  • index.html (this page, live simulation tab) — a JavaScript/Canvas + D3-Delaunay port that runs directly in the browser, no install.
  • matlab/dynamics.m — the original MATLAB implementation, browsable under the matlab version tab.

MATLAB version

The original implementation, in matlab/.

Requires base MATLAB only (delaunayTriangulation, polyshape — no extra toolboxes). Run:

cd matlab
matlab -r dynamics

...or open dynamics.m in the MATLAB editor and run it. You'll be prompted for the number of targets on the loop (1–10). An interactive figure then opens with a control panel (agent speed, ν, L, the track's straight length and corner radius, target spacing, and shared track speed — Apply / Pause / Reset Targets).
